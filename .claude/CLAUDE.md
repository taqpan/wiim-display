# WiiM Pro Pi Display Project

## 概要

WiiM Pro を Raspberry Pi から HTTP API 経由で操作・表示するプロジェクト。
ラズパイに小型モニターを接続し、再生中の楽曲情報の表示と簡単な操作を行う。

## ハードウェア構成

- Raspberry Pi 3 Model B、OS は Raspberry Pi OS（本体対応の最新版）
- モニター: Freenove 5インチ タッチスクリーンモニター（FNK0078 シリーズ）。800x480 IPS、5点静電容量タッチ、MIPI DSI 接続。**横向きで使用する**（ネイティブ解像度が横向きのため回転設定は不要）
- WiiM Pro: 固定IPアドレス（DHCP予約推奨）を割り当てて使用し、値は環境変数で設定する

## 表示要件

- 表示項目: 曲名、アーティスト、アルバム、アルバムアート、再生状態、音量、ミュート状態
- **再生位置（プログレス）は表示しない**
- 画面は 800x480 固定前提でレイアウトする
- 動きのないシンプルな静止レイアウトとする
- **画面デザインの調整のしやすさを重視する**。開発環境で CSS を手で調整できること
- 背景色はアルバムアートの色調（色相と鮮やかさ）から決める。明度と彩度の上限はデザイン側で固定し、アートによらず文字とのコントラストを保つ
- 通信失敗時は前回取得値を保持し、楽曲モードでは表示を維持する。表示を空にしない

## 表示モード

- 楽曲モード（上記の表示項目）と時計モードの2つを持つ
- 時計モード: 左半分に今月のカレンダー、右半分に時分を大きく表示する
  - カレンダーは日曜始まり、英語表記。今日を強調し、土日を色分けする。祝日は扱わない
  - 時刻は24時間表記。OS の時計を使い、画面更新に伴う誤差は許容する
- 電源操作ボタンはどちらのモードでも表示する
- 自動切り替え
  - 曲が無い状態（停止中、曲情報なし、WiiM と通信不能）が一定時間続いたら時計モードにする。一時停止中は曲があるものとして扱う
  - 曲が現れたら楽曲モードに戻す
  - 曲が無い間に手動で楽曲モードへ戻しても、無操作が一定時間続けば時計モードに戻す
  - 曲がある間に手動で時計モードにした場合は、曲がいったん無くなって再び現れるまで維持する

## 操作要件

- 一時停止/再生、音量調整、ミュート切り替え、前後の曲送り
- 表示モードの切り替え（画面右下のボタン）
- 入力方法: タッチ入力

## 応答性の要件

- 状態反映は**数秒の遅延を許容する**。リアルタイム性は要求しない
- 操作に対するフィードバックは即時に返す
- WiiM が無応答でも描画ループを止めない
- 連続失敗時はリトライ間隔を広げる。短い間隔で叩き続けない

## 設定・秘匿情報の扱い

- WiiM のIPアドレス等、環境依存の値は `.env` に分離する
- これらのファイルはリポジトリにコミットしない（`.gitignore` に追加）
- 雛形は `.env.example` に置き、こちらはコミットする

## 開発環境

- Windows ホスト、WSL2 (Ubuntu 24.04) 内で開発を完結する
- Python の実行はすべて Docker コンテナ内で行い、ホストからは `task`（go-task）で操作する。手順は `docs/setup-dev.md`
- `task dev` でサーバを起動し、Windows 側のブラウザから `http://localhost:8080` で確認する
- WiiM 実機に接続せずに画面を確認できるモックモードを用意する
- WiiM HTTP API の外部仕様は `tools/check.py` で実機に対して検証する。単体テストの枠組みは持たない
- 本番の Pi では systemd で Python サーバを起動し、Chromium キオスクから参照する
